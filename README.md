
## **React E-Commerce Website**  
**Live Demo:** [React E-Commerce](https://fatma-zaki.github.io/React-E-Commerce/)  

### **Overview**  
This is a fully responsive e-commerce web application built with **React, Redux, and Tailwind CSS**. It provides users with a seamless shopping experience, allowing them to browse products, add items to the cart, and manage orders efficiently.  

### **Key Features**  
✅ **Modern UI/UX** – Clean and minimalistic design with intuitive navigation.  
✅ **Product Listing** – Dynamic product cards with images, prices, and descriptions.  
✅ **Category Filtering** – Users can filter products by categories (Electronics, Clothing, Jewelry, etc.).  
✅ **Add to Cart** – Users can add and remove items from the cart.  
✅ **Redux State Management** – Ensures smooth data handling and global state management.  
✅ **Responsive Design** – Fully optimized for desktops, tablets, and mobile devices.  
✅ **API Integration** – Fetches real-time product data from a backend API.  
✅ **Loading & Error Handling** – Displays loading states and error messages for better UX.  

### **Development Process**  
1️⃣ **Project Setup**: Created a React project using Vite for faster builds and performance.  
2️⃣ **UI Design**: Designed the layout using Tailwind CSS for efficient styling.  
3️⃣ **State Management**: Implemented Redux Toolkit to manage global state.  
4️⃣ **API Integration**: Fetched product data from a mock API to simulate a real-world store.  
5️⃣ **Cart Functionality**: Added actions to add, remove, and update cart items.  
6️⃣ **Optimization**: Improved performance by lazy-loading components and optimizing assets.  

### **Tech Stack**  
🔹 **Frontend:** React, Redux Toolkit, Vite, Tailwind CSS  
🔹 **State Management:** Redux  
🔹 **API Handling:** Fetch API / Axios  
🔹 **Deployment:** GitHub Pages
